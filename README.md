# Muhammed Malik — Portfolio

A modern personal portfolio website showcasing my skills, projects, experience, and contact information.

## About the Project

This portfolio is a responsive, multi-page website built with HTML, CSS, and JavaScript. It presents a polished personal brand experience with a modern glassmorphism-inspired design, smooth navigation, and animated UI elements.

## Features

- Responsive design for desktop, tablet, and mobile
- Multi-page structure for a complete portfolio experience
- Animated and interactive UI elements
- Skills, projects, blog, and contact sections
- Resume download link
- Built with lightweight front-end technologies

## Technologies Used

- HTML
- CSS
- JavaScript
- Tailwind CSS
- Font Awesome
- Google Fonts

## Getting Started

### Prerequisites

- A modern web browser
- Optional: a local development server for easier preview

### Running Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/mhmdmalik/portfolio.git
   ```
2. Open `index.html` directly in your browser, or serve the project with a local server.

## Customization

You can personalize this portfolio by updating:

- Your name and headline in `index.html`
- Project cards in `projects.html`
- Skills and tools in `skills.html`
- Bio and background in `about.html`
- Contact details in `contact.html`

## Deployment

This project can be deployed easily to GitHub Pages or any static hosting platform.

## Contact

If you'd like to get in touch, use the contact page or update the links with your preferred social profiles.
