Case Study 01 Presence — AI Attendance System

Dual-Verification Attendance: Face Recognition + RSSI Fingerprinting

Problem Statement

Traditional attendance is slow and spoofable. The goal was to build a system that confirms who you are (face) and where you are (location) — both must pass before attendance is marked.

My Role

Designed and built all three layers from scratch: the Flask face-recognition API, the Kotlin Android client (camera + Wi-Fi scanning), and the React + TypeScript admin dashboard.

Solution Architecture

  • Python/Flask REST API exposing /recognize and /train endpoints
  • Custom FaceRecUtils module for encoding, matching & training
  • Android app scans nearby Wi-Fi RSSI values and matches against a stored fingerprint map to verify the user is physically present in the correct room
  • Attendance is recorded only when both face recognition and RSSI location check pass
  • React + TypeScript dashboard (shadcn/ui, recharts) for attendance records and analytics

server.py — Face Recognition API 
from flask import Flask, request, jsonify
from FaceRecUtils import recognize, train
import uuid, os

app = Flask(__name__)

@app.route("/recognize", methods=["POST"])
def recognize_face():
    file = request.files["image"]
    path = f"temp/{uuid.uuid4().hex}.jpg"
    file.save(path)

    person, confidence = recognize(path)
    os.remove(path)

    return jsonify({
        "person": person,
        "confidence": confidence
    })

@app.route("/train")
def train_all():
    return train()   # rebuild face encodings

if __name__ == "__main__":
    app.run(host="0.0.0.0", port=5000)

Key Learnings

The biggest challenge was designing the dual-confirmation gate — face recognition alone isn't enough if someone could mark attendance remotely. Adding RSSI fingerprinting as a second, independent signal (location must also match) makes spoofing significantly harder. Learned Wi-Fi signal processing on Android, confidence-score thresholds for face matching, and coordinating three different tech stacks around a shared API contract.
